## 0. 当前实现状态（2026-06-30）

本阶段只实现合规脚手架，不实现 Reddit 网络采集：

- 新增 `SocialHeatSnapshot`，可保存 provider、ticker、提及数、基线数、热度分、情绪分、窗口、来源状态和证据 URL。
- 新增默认关闭配置：`social_heat.enabled=false`、`social_heat.provider=manual`、`social_heat.lookback_hours=24`、`social_heat.baseline_days=30`。
- 新增手动 upsert/query helper，供后续官方 Reddit API provider 或人工 CSV 导入复用。
- 社交热度不参与当前 A/B 基本面等级硬条件，也不会在缺失时降低候选等级；只作为可选研究增强。

未实现且不得隐式开启：

- 未授权网页抓取 Reddit。
- 自动保存用户身份或个人数据。
- 将社交热度作为买卖信号或自动交易触发器。

## 1. 目标

在不影响基本面 A/B 等级的前提下，使用 Reddit 官方 OAuth Data API 识别候选公司的关注度变化。该模块默认关闭、完全可选。

## 2. 合规边界

- 只使用官方 API 和用户合法提供的凭据/访问资格。
- 不抓取网页、不绕过访问限制、不尝试规避配额。
- 不长期保存不必要的完整帖子正文和个人资料。
- 凭据加密保存，API 和日志中始终掩码。
- API 权限或政策不允许时保持模块关闭，不寻找规避方案。

## 3. 数据范围

管理员维护 subreddit allowlist。系统识别 Ticker、带 `$` 的 cashtag 和公司名称，同时维护常用英文词冲突表。

每日指标：

- 帖子、评论、去重作者和提及次数。
- 净得分、评论互动量。
- 单一作者集中度和重复文本比例。
- 最近 24 小时相对过去 30 天同星期/时段基线的 z-score。

只保存指标快照、Reddit 内容 ID、时间和最小必要证据；原始正文缓存按短期保留策略清理。

## 4. 热度状态

输出 `cold`、`normal`、`rising`、`spike`。阈值由配置版本控制，且至少满足最小帖子数、去重作者数和非冲突 Ticker 条件。

单一作者占比过高、重复文本明显、低样本或 Ticker 与常用词冲突时标记 `manipulation_risk` 或 `ambiguous_symbol`，不得发送 spike 通知。

## 5. 与评分系统的关系

- Reddit 指标不进入基本面 100 分。
- Reddit 不能使公司晋级 A/B，也不能抵消融资或持续经营风险。
- 页面将热度与基本面等级并列展示，明确标注“关注度，不代表利好”。
- Provider 失败只影响热度数据，不影响 SEC、评分、候选和基本面通知。

## 6. 调度与限流

任务根据官方配额动态控制频率，默认每小时一次。429 使用有上限退避；达到配额后停止本周期并记录 partial，不启用并发重试风暴。

每次运行保存 allowlist 版本、查询窗口、配额状态、处理量和失败原因。相同窗口重复运行按内容 ID 去重。

## 7. 通知

仅对已在预筛池的公司发送 `spike` 摘要，默认不即时推送。用户启用即时推送时，同公司 24 小时最多一次，并附样本量和操纵风险。

## 8. 验收

- 模块关闭时不发请求、不创建空告警、不影响其他任务。
- 凭据不会出现在日志、API 或导出文件。
- 常用词 Ticker、低样本和集中刷量样本不会触发 spike 通知。
- 同窗口重复同步不会重复计数。
- Reddit 失败不会改变任何公司的基本面评分和等级。
- API 配额耗尽时任务可控停止并在健康页显示原因。
